# Machine-Learning
Test Projects to learn ML

Key Takeaways & Conclusion
Feature Engineering & Data Quality: Even advanced models cannot extract predictive power without a underlying data signal ("Garbage In, Garbage Out").

Benchmark Against Baselines: Comparing models against a simple DummyClassifier baseline prevented misinterpreting subpar accuracy scores as model successes.

Optimal Architecture: For this specific dataset, Regression via tuned Random Forest offers the most robust modeling strategy.
